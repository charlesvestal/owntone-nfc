Card artwork

Finds cover art for albums that have no card yet, then lays it out as A4 sheets of 95 mm squares — the same size as the cards already in the box.

A search can return a confidently wrong album, so anything doubtful is flagged. Look before you print.

Tick that to reprint a whole set. Artwork for albums that already have cards has never been collected, so Collect will fetch it first — and the grid then shows exactly what will print.

 

 

Power

Pulling the plug on a running Pi is how SD cards get corrupted.

 

Music library

The library is a read-only network mount, so OwnTone gets no notification when an album is added and will not find it on its own. The nightly rescan at 04:30 only runs if the box happens to be switched on then.
